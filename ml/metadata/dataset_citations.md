## Usage Notes

When using these datasets in publications or derivative works:

1. **Include the appropriate citation** for each dataset used
2. **Respect license terms** - some datasets require non-commercial use only
3. **Provide attribution** as specified by each dataset's license
4. **Acknowledge the original creators** and funding sources where applicable
5. **Check for specific citation requirements** in each dataset's documentation
